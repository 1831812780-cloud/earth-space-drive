# EARTH — 驾驶者视角

React / TypeScript / Vite / Three.js / React Three Fiber。窗外的地球与月球为实时 WebGL，驾驶舱、双手与方向盘为透明图片图层。使用真实地理纹理，来源与许可见 ASSETS.md。

## 启动

macOS 双击 `start.command`，或在项目目录执行：

```sh
export PATH="$PWD/.tools/bin:$PATH"
npm run dev -- --port 5173 --strictPort
```

打开 http://localhost:5173/ 。换电脑请安装 Node 22+ 后执行 `npm ci`。构建 `npm run build`，验证 `npm test`。本地服务关闭后网址就无法访问，重新启动即可。原地月交互场景保留在 `/?view=orbit`。

## 当前操作

- 只使用键盘：↑ / W 前进，↓ / S 后退，← → / A D 转向。
- 释放按键后平滑减速；失去焦点时清空按键。
- 「重置视角」恢复初始距离、方位与方向盘姿态。
- 页面不启动摄像头，不加载识别器，也没有摄像头权限入口。
- 左侧窗框暖色灯每 2 秒闪烁一次。
- 双手/方向盘图层限制在 ±12°，加大下方图像余量，避免最大转向时露出裁切边缘。

## 音乐

默认背景音乐为用户提供的 Space Oddity (Mitty Mix)，本地文件 `public/audio/space-oddity-mitty-mix.mp3`，约 5 分 11 秒。音乐面板、歌曲信息和原生进度条全部隐藏。首次点击画面或按驾驶键启动音乐；M 键暂停/继续。默认音量 50%，不循环，无需连接 YouTube。

暂停或自然播放结束会重置驾驶视角并清空输入。歌曲结束后不会因驾驶按键自动重播，按 M 可重新播放。首次播放仍由用户操作触发。

## 运动和参数

`src/driving/state.ts`：初始距离 5.8 个地球半径，最近 1.65，最远 12；驾驶速度、转向速度、演示周期。

当前驾驶模式地球 240 秒自转一圈，月球 600 秒公转/同步自转一圈。这是便于观察的独立时间压缩，不是实时天文学时间比例；月球仍保持同一面朝向地球。月地直径比 0.2727，轨道距离为了同屏观看压缩为 2.6 个地球半径。原 `?view=orbit` 场景保留 45 秒地球周期与约 27.4 倍月球周期的比例。

`DriverCamera.tsx`：前后改变距离，转向改变绕地球的方位，镜头持续朝向地球。属于观景驾驶，不是完整航天动力学。

`config.ts`：太阳方向、云透明度、地轴倾角、大气强度、DPR 与地球参数。`Earth.tsx`、`Clouds.tsx`、`Atmosphere.tsx`、`Moon.tsx` 管理各天体图层；`shaders.ts` 统一自然明暗，海洋遮罩控制反射。纹理按设备启发式选择 2K / 4K / 8K。

## 已知边界

驾驶舱不是完整 3D 汽车，手臂随方向盘图层旋转。地表和云为静态卫星数据衍生合成纹理，不是实时天气。轻量散射与材质着色不等同于光谱级物理模拟。月球采用圆轨道近似，未模拟食、天平动及共同质心。iPhone Safari 和长时间热负载帧率仍需真机检查。
